# Sentinel v0.1.0

First public release of Sentinel, an offline Python security log analyzer for SSH authentication activity.

## Highlights

- Detect repeated SSH failures, failures across multiple usernames, and successful logins following failures.
- Analyze traditional/ISO syslog or journal JSON lines from plain logs, gzip rotations, or stdin.
- Review host/source/account correlations and source-line evidence in text or JSON reports.
- Tune thresholds, time windows, year, and timezone assumptions without adding dependencies.
- Use the included synthetic fixtures, documentation, and community contribution guides.

## Install and try

Python 3.10+ is required. Download the wheel attached to this release and install it in a virtual environment:

```sh
python -m pip install sentinel_log_analyzer-0.1.0-py3-none-any.whl
sentinel --version
sentinel analyze /path/to/auth.log --year 2026
```

For a safe demo, clone the repository and run `python -m sentinel analyze examples/auth.log --year 2026`. It produces three alerts; `examples/clean.log` matches no rules. The source distribution also includes these examples.

## Validation

The release workflow runs the regression suite and installed-CLI smoke test on Ubuntu before publishing these assets. The main-branch CI matrix covers Python 3.10/3.13 on Ubuntu and Windows. Review the linked workflow runs for the exact results. Local Windows testing before publication passed 35 tests with one environment-related hard-link skip; four deliberate detector mutations were rejected by the regression tests.

## Limitations

This early release is scoped to SSH authentication records. It is a batch analyzer, retains events in memory, and does not deduplicate overlapping exports. Traditional syslog needs the correct starting year and UTC offset. Indicators are not proof of compromise. There is no live monitoring, state persistence, remediation, or PyPI publishing.
